# AnkiCards · Coral Glass

Исходники логотипа и краткая сводка визуальной системы. Токены в коде — `src/index.css`.

## Логотип

| Файл | Назначение |
|---|---|
| `mark.svg` | Мастер-геометрия знака (viewBox 48×48). Задняя карточка наклонена на −13°, передняя вертикальная, загиб в правом верхнем углу |
| `app-icon.svg` | Иконка «Coral Glass» на всю площадь (для iOS и maskable), из неё собраны `public/icon-512.png`, `icon-192.png`, `apple-touch-icon.png` |
| `src/ui/Logo.tsx` | Та же геометрия в интерфейсе: `LogoMark` (currentColor, `simple` — без загиба для 16 px) и `Logo` (знак + AnkiCards) |

Правила: охранное поле не меньше ¼ высоты знака, между знаком и названием около ⅓. Наклон не менять, не растягивать, чёрный вариант не ставить на тёмный фон. Стеклянный рендер не мастер-файл.

Радиусы: поле 14, кнопка 18, карточка 24, плавающая панель 30. Боковые поля 20 px (16 px на ширине до 360).

## Стекло

Только нижняя навигация, шапка при прокрутке, листы и тосты (класс `.glass`). Без поддержки `backdrop-filter` или с настройкой «Уменьшить прозрачность» (класс `.solid` на `<html>`) — непрозрачная поверхность с тонкой границей.

## Движение

Раскрытие ответа 200 мс (прозрачность + сдвиг 4 px), нажатие 100–150 мс, лист 260 мс. При `prefers-reduced-motion` анимации практически мгновенные.
